# AdvanceX Demo Pack

Source folder of an example `.advx` enhancement pack. It targets the
AdvanceX test cartridge (`tools/testrom`) only, so it is entirely legal to
redistribute.

Build the installable package with:

```sh
tools/pack-advx.sh mods/examples/advancex-demo-pack build/advancex-demo-pack.advx
```

See `docs/MODDING.md` for the format.
